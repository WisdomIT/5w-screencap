Gen5W 헤드유닛 화면(1920×720px, 1280×480dp) 비율 그대로 그렸습니다. 아래 두 화면은 직접 조작할 수 있습니다. 플로팅 버튼을 드래그하거나 화면 밖으로 밀어 보세요.

1. 평소 화면 + 플로팅 버튼

탭하면 캡처, 0.6초 길게 누르면 녹화 시작, 녹화 중 탭하면 정지합니다. 드래그해서 놓으면 가까운 좌우 가장자리에 붙고, 절반 넘게 화면 밖으로 밀면 작은 ‹ 태그로 접힙니다. 버튼은 캡처 대상 레이어 위에 있어서 사진과 영상에는 찍히지 않습니다.
