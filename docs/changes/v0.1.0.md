### 기능
- **화면 캡처**: 지금 보이는 화면(CarPlay·Android Auto 포함)을 1920×720 JPEG로 USB에 저장합니다. 약 0.5초 걸리고, 셔터음과 알림으로 알려 줍니다.
- **영상 녹화**: 화면을 MPEG-4 영상으로 녹화해 2분 단위 MP4로 나눠 저장합니다. 화질은 표준(1024×384, 약 12fps), 선명(1280×480, 약 8fps), 원본(1920×720, 약 3fps) 중에서 고릅니다. 소리는 녹음하지 않습니다.
- **버튼**: 캡처와 녹화에 각각 버튼(운전대 ☆·MODE·음소거·통화, RADIO, MEDIA 등 12가지)과 누르는 방식(1회, 1회·원래 기능 막기, 길게, 연속 2회)을 고릅니다. 차량 ☆ 버튼 설정에서 "화면 캡처", "화면 녹화 시작/정지"를 고를 수도 있습니다. 녹화 중에 캡처 버튼을 누르면 녹화를 멈춥니다.
- **플로팅 버튼**: 탭하면 캡처, 길게 누르면 녹화, 녹화 중 탭하면 정지. 드래그로 옮기고 화면 밖으로 밀면 작은 태그로 접힙니다. 녹화 중에는 시간이 보이고, 사진과 영상에는 찍히지 않습니다. USB가 꽂혀 있을 때만 보입니다.
- **설정 화면** (앱 메뉴 "화면 캡처"): 캡처 테스트, 버튼·녹화 설정, USB 연결 시 자동 녹화, 8단계 진단(진행 표시, 결과 요약, SUMMARY.txt), 차 정보가 채워진 이슈 신고 QR.

### 알아 둘 것
- HMG-API 1.0 이상이 필요합니다. 설치 후 재부팅하세요.
- 녹화를 멈춘 뒤 "녹화 저장됨" 알림을 보고 USB를 빼세요. 녹화 중에 빼면 그 2분 구간 파일은 재생되지 않습니다.
- 시동이 꺼질 때 녹화 파일을 마저 닫는 기능은 HMG-API 1.1.0 이상에서 동작합니다.
- 후방카메라 화면은 찍히지 않을 수 있습니다.
