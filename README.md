# 5w-screencap

현대·기아 내비게이션(Gen5W)의 화면을 **버튼 한 번으로 사진 찍고, 주행 중 영상으로 녹화해 USB에 저장**하는 [HMG-API](https://github.com/Open-HMG/HMG-API) mod입니다.

- 내비, CarPlay, Android Auto, 차량 설정 등 **내비게이션에 보이는 화면 그대로** 저장합니다.
- 운전대·내비 버튼, 차량 ☆ 버튼 메뉴, 화면의 작은 플로팅 버튼으로 조작합니다. 운전 중에는 화면을 보지 않고 버튼과 소리만으로 쓸 수 있습니다.
- 차량 시스템 파일은 고치지 않습니다. 결과물은 꽂아 둔 USB에만 저장합니다.

> ⚠️ 비공식 개조입니다. 설치와 사용에 따른 책임은 차 주인에게 있습니다. 설치와 설정은 **차를 안전한 곳에 세운 상태**에서 하세요. 운전 중에는 화면을 조작하지 말고 하드웨어 버튼을 쓰세요.

---

## 시작하기 전에 확인하세요

| 필요한 것 | 확인 방법 |
|---|---|
| **Gen5W 내비게이션** (Android 기반) | 차의 **설정 → 일반 → SW 정보**에서 버전 문자열에 **`S5W_M`**이 들어 있어야 합니다. `S5W_L`이나 ccNC 내비는 지원하지 않습니다. 동작이 확인된 차는 [동작 확인 차량](docs/COMPATIBILITY.md)에 있습니다. |
| **NEMESIS** | HMG-API가 NEMESIS 위에서 동작합니다. 아래 "NEMESIS와 HMG-API 설치"를 보세요. |
| **HMG-API 1.0 이상** | 버튼 연결, ☆ 메뉴, 설정 저장을 HMG-API가 맡습니다. |
| **USB 메모리** | FAT32 또는 exFAT. 녹화는 분당 최대 약 11~15MB입니다. |
| **컴퓨터** | Windows PC 또는 Mac (파일을 받아 USB에 복사하는 용도) |

### NEMESIS와 HMG-API 설치

이 프로젝트가 만든 것이 아니므로 각 공식 안내를 따라 설치하세요.

- **NEMESIS** (설치 방법, 호환 차량): https://github.com/xwtk/hmg_nemesis
- **HMG-API** (설치 방법, 버튼·mod 관리): https://github.com/Open-HMG/HMG-API

설치되어 있는지 확인하는 방법: 내비게이션의 **NAV 버튼을 1.5초 안에 빠르게 3번** 누르면 **NEMESIS Manager**가 열립니다. 앱 메뉴에 **HMG-API** 타일이 있으면 HMG-API도 설치된 것입니다.

## 설치

### 1단계: 설치 파일 받기

1. [최신 릴리스 페이지](https://github.com/WisdomIT/5w-screencap/releases/latest)를 엽니다.
2. 아래쪽 **Assets**에서 **`5w-screencap-버전-usb.zip`**을 받습니다(예: `5w-screencap-0.1.0-usb.zip`).

| 파일 | 누가 받나요 |
|---|---|
| `5w-screencap-버전-usb.zip` | **대부분은 이것만 받으면 됩니다.** USB에 넣을 것이 모두 들어 있습니다. |
| `5w-screencap-버전.zip` | HMG-API mod 파일만. HMG-API의 USB 업데이트(`HMGAPI/updates/` 폴더)나 adb로 설치하는 분용입니다. |
| `5w-screencap-버전-nemesis-package.zip` | NEMESIS 패키지만. NEMESIS 설치 파일을 직접 다루는 분용입니다. |
| `SHA256SUMS.txt` | 받은 파일이 손상되지 않았는지 확인하는 값입니다. |

### 2단계: USB 준비하기

USB를 **FAT32**(또는 exFAT)로 포맷합니다. 포맷하면 USB 안의 파일이 **모두 지워지니** 필요한 파일은 먼저 옮겨 두세요. 이미 NEMESIS·HMG-API용으로 쓰는 USB가 있다면 그대로 써도 됩니다.

**Windows**
1. USB를 꽂고 파일 탐색기의 **내 PC**에서 USB 드라이브를 **마우스 오른쪽 버튼**으로 누른 뒤 **포맷...**을 고릅니다.
2. **파일 시스템**을 **FAT32**로 고르고 **시작**을 누릅니다. 목록에 FAT32가 없으면 USB가 32GB보다 큰 것이니 **exFAT**을 고르세요.

**Mac**
1. USB를 꽂고 **디스크 유틸리티**를 엽니다(Spotlight에서 "디스크 유틸리티" 검색).
2. 왼쪽에서 USB를 고르고 **지우기**를 누릅니다.
3. 포맷은 **MS-DOS(FAT)**(32GB보다 크면 **ExFAT**), 방식은 **마스터 부트 레코드**를 고르고 **지우기**를 누릅니다.

### 3단계: USB에 복사하기

1. 받은 **`5w-screencap-버전-usb.zip`의 압축을 풉니다.**
2. 풀린 내용물 **`NEMESIS.data` 파일과 `packages` 폴더**를 USB의 **맨 위(첫 화면)**에 복사합니다.

USB를 열었을 때 이렇게 보여야 합니다.

```
USB
├── NEMESIS.data
└── packages
    └── hmgapi.5w-screencap.zip
```

자주 틀리는 부분:
- ❌ `packages` 안의 `hmgapi.5w-screencap.zip`은 **풀지 마세요.** 그대로 둡니다.
- ❌ 압축을 푼 **폴더째로** USB에 넣지 마세요. `NEMESIS.data`가 USB 맨 위에 바로 있어야 합니다.
- ❌ `NEMESIS.data`를 메모장 등으로 새로 만들지 마세요. 이름이 `NEMESIS.data.txt`가 되어 차가 알아보지 못합니다.
- Mac에서는 복사 후 USB를 **꺼내기**한 다음 뽑으세요.

### 4단계: 차에 설치하기

1. 시동을 켜고(또는 ACC ON) **내비게이션 첫 화면이 완전히 뜰 때까지** 기다립니다.
2. USB를 차의 USB 단자에 꽂습니다.
3. NEMESIS가 설치할지 묻는 창을 띄우면 **예**를 누릅니다. 60초 안에 누르지 않으면 창이 사라지니, 그때는 USB를 뽑았다 다시 꽂으세요.
   - 이미 설치된 상태에서 새 버전을 넣었다면 **업데이트할지** 묻습니다. 이때도 **예**를 누릅니다.
4. "installed" 알림이 뜨면 설치가 끝난 것입니다.

### 5단계: 재부팅하기

**설치 직후에는 버튼이 바로 연결되지 않을 수 있습니다.** HMG-API가 버튼을 다시 연결하도록 재부팅하세요.

1. NAV 버튼을 빠르게 3번 눌러 **NEMESIS Manager**를 엽니다.
2. **Settings → Reboot**을 누릅니다.

> 시동을 잠깐(3분 정도) 껐다 켜는 것으로는 재부팅되지 **않습니다**. 이때 내비는 꺼지지 않고 화면만 꺼졌다 켜집니다.

### 6단계: 확인하기

1. 앱 메뉴에서 **"화면 캡처"** 타일을 누르면 설정 화면이 열립니다. (NEMESIS Manager의 Launch는 HMG-API 앱을 엽니다)
2. 오른쪽 위에 **"서비스 동작 중"**이 보이면 정상입니다.
3. USB를 꽂은 채 **테스트 캡처**를 누르면 썸네일과 "정상 · 1920×720 · 0.5초 · 플로팅 버튼 제외됨"이 나옵니다.
4. 버튼과 녹화 화질을 고릅니다([쓰는 법](#쓰는-법)).

### 업데이트

새 버전도 설치와 똑같이 하면 됩니다. 새 `-usb.zip`을 받아 USB 맨 위에 복사하고, 차에 꽂아 **예**를 누른 뒤 재부팅합니다. 버튼과 녹화 설정은 그대로 남습니다. USB에 있던 예전 `NEMESIS.data`와 `packages` 폴더는 덮어쓰거나 지우세요.

## 되돌리기 (삭제)

| 방법 | 결과 |
|---|---|
| HMG-API 앱 → Mods → 5W Screencap → 제거 | mod와 앱, 서비스, 버튼 연결이 모두 빠집니다. |
| NEMESIS Manager → My Packages → 5W Screencap → **Uninstall** | 위와 같습니다(HMG-API를 통해 지웁니다). |

시스템 파일을 고치지 않으므로 복원할 것이 없습니다. USB에 저장된 사진과 영상은 지워지지 않습니다.

## 쓰는 법

| 하는 일 | 방법 |
|---|---|
| **사진 찍기** | 고른 캡처 버튼, 차량 ☆ 메뉴의 "화면 캡처", 또는 플로팅 버튼 탭 |
| **녹화 시작** | 고른 녹화 버튼, ☆ 메뉴의 "화면 녹화 시작/정지", 또는 플로팅 버튼 0.6초 길게 누르기 |
| **녹화 정지** | 녹화 버튼을 한 번 더, **녹화 중에 캡처 버튼**, 또는 플로팅 버튼 탭 |

- 사진을 찍으면 **셔터음**과 "캡처 저장됨" 알림이, 녹화를 시작·정지하면 **비프음**과 알림이 나옵니다.
- 녹화를 멈춘 뒤 **"녹화 저장됨 · N분 N초"** 알림을 보고 USB를 빼세요. 녹화 중에 빼면 그 2분 구간 파일은 재생되지 않습니다.

### 버튼 고르기

설정 화면의 **버튼** 카드에서 캡처와 녹화에 각각 버튼과 누르는 방식을 고릅니다. HMG-API 앱의 mod 설정에서도 같은 내용을 고를 수 있습니다.

| 버튼 | 운전대 ☆, 헤드유닛 ☆, 운전대 MODE, 운전대 음소거, 운전대 통화, RADIO, MEDIA, FM/AM, SETUP, PHONE, MAP, TUNE 누름 |
|---|---|

| 누르는 방식 | 동작 |
|---|---|
| 1회 누름 | 손을 뗄 때 바로 실행. 그 버튼의 원래 기능도 실행됩니다. |
| 1회 누름 · 원래 기능 막기 | 손을 뗄 때 바로 실행. 원래 기능은 실행되지 않습니다. 거의 안 쓰는 버튼(RADIO 등)에 좋습니다. |
| 길게 누름 | 0.8초 누르면 실행. 그 버튼의 원래 **길게 누름** 기능만 대신하고, 짧게 누르면 원래대로 동작합니다. |
| 연속 2회 | 0.4초 안에 두 번 누르면 실행. 이 버튼의 원래 기능은 항상 꺼지고, 한 번만 누르면 아무 일도 없습니다. |

- **☆ 버튼의 1회 누름**은 차량 설정 → 버튼 → ☆ 에서 "화면 캡처" 또는 "화면 녹화 시작/정지"를 골라야 동작합니다. 이 mod가 ☆ 메뉴에 항목을 추가합니다.
- 추천: **MODE 짧게 = 사진, MODE 길게 = 녹화**. 녹화 중에 MODE를 짧게 누르면 녹화가 멈춥니다.
- 같은 버튼의 같은 누르는 방식을 캡처와 녹화에 함께 쓸 수는 없습니다.

### 플로팅 버튼

USB가 꽂혀 있을 때 화면 구석에 동그란 버튼이 나옵니다. **사진과 영상에는 찍히지 않습니다.**

| 조작 | 동작 |
|---|---|
| 탭 | 사진 (녹화 중이면 정지) |
| 0.6초 길게 누르기 | 녹화 시작 (링이 다 차면 시작) |
| 드래그 | 옮기기. 놓으면 가까운 쪽 가장자리에 붙습니다. |
| 화면 밖으로 반 넘게 밀기 | 작은 `‹` 태그로 접힘. 태그를 누르면 다시 나옵니다. |
| 녹화 중 | 빨간색으로 바뀌고 녹화 시간이 나옵니다. 접힌 태그에도 빨간 점과 시간이 보입니다. |

설정 화면의 **플로팅 버튼 표시**로 끌 수 있습니다.

### 녹화 화질과 저장

| 화질 | 크기 | 속도 | 용량 |
|---|---|---|---|
| 표준 (기본) | 1024×384 | 약 12fps | 최대 약 11MB/분 |
| 선명 | 1280×480 | 약 8fps | 최대 약 15MB/분 |
| 원본 | 1920×720 | 약 3.5fps | 최대 약 15MB/분 |

- 저장 위치: USB의 `5W-Screencap/Screenshots/날짜_시간.jpg`, `5W-Screencap/Recordings/날짜_시간_001.mp4`
- 녹화는 **2분 단위 MP4**로 나뉩니다. 시동이 갑자기 꺼져도 앞 파일들은 안전합니다.
- 내비 시계가 아직 맞춰지지 않았을 때(2015년으로 표시)는 날짜 대신 `boot0042_003`처럼 번호로 저장합니다.
- **USB 연결 시 자동 녹화**를 켜면 USB를 꽂을 때 녹화를 시작합니다.
- 소리는 녹음하지 않습니다. 차량 스피커 소리를 녹음할 방법이 없습니다([4차 진단 결과](diag/results/FINDINGS-20261119-niro-diag4.md)).
- 후방카메라 화면은 별도 하드웨어 레이어라 찍히지 않을 수 있습니다.

## 설정 화면

앱 메뉴의 **"화면 캡처"** 타일로 엽니다. 화면이 넘치면 왼쪽 영역을 위아래로 스크롤하고, 오른쪽 위 **닫기 ✕**로 홈 화면에 돌아갑니다.

- **왼쪽**:
  - 버전과 서비스 상태 배지(서비스 동작 중 / 녹화 중 / 캡처 서비스 응답 없음)
  - **캡처 테스트**: 지금 화면을 찍어 썸네일, 걸린 시간, 플로팅 버튼 제외 여부를 보여 줍니다.
  - **버튼**: 캡처·녹화 버튼과 누르는 방식. 바꾸면 바로 저장되고 바로 적용됩니다.
  - **녹화**: 화질, USB 연결 시 자동 녹화, 플로팅 버튼 표시, USB 남은 공간
  - **진단**: 아래 [문제 알리기](#문제-알리기-github-이슈)
- **오른쪽**: 휴대폰으로 스캔하면 GitHub 이슈 작성 화면이 열리는 QR입니다. 이 차의 펌웨어와 버전이 미리 채워집니다.

화면이나 알림에 나오는 문구:

| 문구 | 뜻과 해결 방법 |
|---|---|
| USB를 연결하세요 | USB가 없어서 저장하지 않았습니다. 내부 저장소에는 쓰지 않습니다. |
| USB 공간이 부족합니다 | 남은 공간이 64MB 아래입니다. 지난 녹화를 옮기거나 지우세요. |
| 캡처 서비스가 응답하지 않습니다 | HMG-API 앱에서 5W Screencap이 켜져 있는지 확인하고 재부팅하세요. |
| 녹화가 멈췄습니다: USB가 분리됐습니다 | 녹화 중에 USB가 빠졌습니다. 그 2분 구간 파일은 재생되지 않을 수 있습니다. |
| 녹화가 멈췄습니다: USB 공간이 부족합니다 / 인코더 오류 | 녹화 중 공간이 찼거나 인코더가 멈췄습니다. 앞의 2분 단위 파일은 남아 있습니다. 인코더 오류가 반복되면 진단을 실행해 신고해 주세요. |
| 녹화 파일을 마무리하지 못했습니다 | 파일을 닫지 못했습니다. 진단을 실행해 신고해 주세요. |

## 문제 알리기 (GitHub 이슈)

### 1. 진단 실행
1. FAT32 또는 exFAT USB를 차에 꽂습니다.
2. 설정 화면(앱 메뉴 "화면 캡처")을 엽니다.
3. **진단 실행**을 누릅니다.
   - 8단계(버전 정보, 화면 정보, 화면 캡처, 인코더, 녹화 시험, USB, 로그, 저장)를 차례로 확인합니다. 진행 중에는 지금 단계와 하는 일, 경과 시간이 보이고, 끝난 단계는 ✓(문제가 있으면 ✗)로 표시됩니다. 보통 20초 안팎입니다.
   - **"진단 완료"가 뜰 때까지 USB를 뽑지 마세요.**
4. 끝나면 단계별 한 줄 결과가 나오고, USB의 `5W-Screencap/diag/날짜_시간/` 폴더에 `SUMMARY.txt`가 생깁니다.

### 2. 이슈 작성
- 설정 화면 오른쪽의 **QR**을 휴대폰으로 스캔하면 버그 신고 양식이 열립니다. 펌웨어와 버전이 미리 채워집니다.
- 컴퓨터에서는 [이슈 작성](https://github.com/WisdomIT/5w-screencap/issues/new/choose)에서 양식을 고르세요.
  - **버그 신고**: 캡처·녹화가 안 됨, 버튼이 반응하지 않음, 화면이 이상함, 설치·삭제 문제
  - **기능 제안**
  - **차량 호환성 보고**: 내 차에서 잘 되는지 알리기. 잘 되는 경우도 환영합니다.

### 3. 어떤 파일을 올리나요
| 파일 | 올리기 | 내용 |
|---|---|---|
| `5W-Screencap/diag/날짜_시간/SUMMARY.txt` | **항상** | 버전, 화면, 캡처·인코더·녹화 시험 결과, USB, 이 mod의 로그 |
| 캡처 사진, 녹화 영상 | 필요할 때만 | **지도와 위치, 휴대폰 화면이 담깁니다.** 꼭 필요한 부분만 올리세요. |

진단 결과에는 시리얼, BT·Wi-Fi·MAC 주소, 사용자 파일 이름, 캡처 이미지를 담지 않습니다. 그래도 올리기 전에 한 번 훑어보세요.

## 직접 빌드해서 설치 (개발자용)

JDK 17 이상과 Python 3가 필요합니다. Android SDK는 필요 없습니다. 빌드 도구(aapt2, r8, android-all 4.4)와 HMG-API mod SDK는 처음 빌드할 때 버전과 sha256을 고정해 내려받습니다.

```bash
tests/run.sh
```

빌드, `mod.json` 검사, HMG-API 엔진 검사(mod SDK로 가짜 헤드유닛에서 설치·버튼 연결 확인), 단위 테스트를 한 번에 합니다.

```bash
tools/package.sh
```

`dist/release/`에 설치 파일 3종과 `SHA256SUMS.txt`를 만듭니다. 서명 키(`~/.5w-screencap/`)가 없으면 앱 키는 새로 만들고, mod 키는 만드는 방법을 알려 줍니다([docs/RELEASING.md](docs/RELEASING.md)).

## 동작 원리

### 화면을 가져오는 방법
- 차의 화면 합성기(SurfaceFlinger)에서 화면을 바로 가져옵니다(`SurfaceControl.screenshot`, root로 도는 `screencapd` 서비스). 1920×720 한 장에 약 15ms입니다.
- 플로팅 버튼은 상태바보다 위 레이어(`TYPE_SYSTEM_ERROR`, 22)에 띄우고, 화면은 그보다 아래 레이어만 가져옵니다. 그래서 버튼과 녹화 시간이 사진과 영상에 찍히지 않습니다.

### 녹화
- Android 내장 `screenrecord`는 이 내비의 인코더가 받지 못하는 입력 방식을 써서 동작하지 않습니다. 하드웨어 H.264 인코더는 시작되지 않고, 소프트웨어 H.264는 CIF 크기까지만 됩니다([구현 가능성 검토](diag/results/FINDINGS-20261119-niro-diag3.md)).
- 그래서 화면을 일정 간격으로 가져와 색 변환(RGBA → I420)한 뒤 **소프트웨어 MPEG-4 인코더**로 MP4를 만듭니다. 화질별 속도는 이 경로의 실측값입니다.
- MP4는 닫혀야 재생되므로 2분 단위로 나눕니다. 파일마다 인코더 설정(VOL 헤더)을 새로 넣고, 시간값이 뒤로 가는 프레임은 버려서 이 내비의 MP4 기록기가 파일을 버리지 않게 합니다.

### 버튼
- 버튼은 HMG-API가 system_server에서 받아 이 mod의 앱에 알려 줍니다. "원래 기능 막기"는 HMG-API가 그 누름을 차에 넘기지 않는 것입니다.
- HMG-API의 조건(`when`)은 설정값 하나만 비교하므로, "버튼 + 누르는 방식"을 하나의 숨은 설정값으로 합쳐 두고 후보마다 바인딩을 미리 만들어 둡니다(`tools/gen_input.py`, 84개). 설정을 바꾸면 HMG-API가 바로 맞는 바인딩만 켭니다.
- 연속 2회는 HMG-API가 지원하지 않아 앱이 직접 셉니다.

### 안전장치
- USB가 없으면 내부 저장소에 쓰지 않습니다. 남은 공간이 64MB 아래면 시작하지 않습니다.
- 녹화 중 USB가 빠지거나 공간이 차면 녹화를 멈추고 알립니다.
- 플로팅 버튼이 사라지면(QuickBoot 복귀 등) `screencapd`가 20초 안에 다시 띄웁니다.
- HMG-API 1.1.0 이상에서는 시동이 꺼지기 직전에 녹화 파일을 닫습니다.

tools/build.sh                   서비스와 앱 빌드 (Android SDK 없이)

tools/release.sh                 릴리스 파일 생성과 게시 (docs/RELEASING.md)
tests/                           mod.json 검사, HMG-API 엔진 검사, JVM 단위 테스트
diag/ ~ diag4/                   구현 가능성 검토 때 쓴 실차 진단 (diag/results/에 결과)
docs/                            동작 확인 차량, 릴리스 절차, 버전별 변경 내역, 화면 설계
